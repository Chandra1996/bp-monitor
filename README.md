# BP Monitor – get your APK in ~5 minutes (free, no Android Studio)

1. Create a free account at https://github.com and click **New repository** (name: bp-monitor, Private is fine).
2. Click **uploading an existing file**, drag in ALL files/folders from this zip
   (keep the `.github` folder – if your file manager hides it, use "Add file > Upload files" on the folder contents), then **Commit**.
3. Open the **Actions** tab. The "Build APK" workflow starts automatically (takes ~5–8 min). If not, click it > **Run workflow**.
4. When it shows a green tick, open the run and download **BP-Monitor-debug-apk** under *Artifacts* (a zip containing app-debug.apk).
5. Send the APK to your phone, tap it, allow "Install unknown apps", install.
